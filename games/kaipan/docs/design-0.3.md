# 《开盘》0.3 设计稿：散户、题材轮动、群聊、月供

> 状态：M0（原型）用，0.3.0 正式版沿用。规则核心已实现（2026-10-10），数值按第 11 节调过；第 14 节是实现时的决定和细化，
> 其中 14.1 是 0.3.0 正式版（人设、难度、成就、新内容）的定稿。
> 内容 id 固定，美术按 id 出图。
> 规划和动机见 docs/plan-0.3.md；0.2 的设计在 docs/design-0.2.md，代码在 git 的 0.2.0 提交里。

## 0. 设计支柱

1. 简单易上手：每天最多点两下（买一只或卖一只，然后开盘）。
2. 模拟炒股：题材轮动、龙头与跟风、连板与炸板、T+1、群聊里的小道消息、月供压力。
3. 轻松幽默：股票是有表情的小人，群友各有性格，账单名目越来越离谱。全部虚构，
   不出现真实公司、真人、真实机构、政治、军事或真实社会事件。
4. 一个数字、一条主线：账户余额是唯一的分数和货币；所有内容都通过"题材"和"角色"起作用。
5. 搭配丰富：规则表只有几行，每个道具只改其中一格，组合靠题材集中、角色搭配、消息来源。
6. 自己的特色：骨架来自 A 股本身；借鉴别的游戏只借一点精神（见 plan-0.3.md 第 5 节）。
7. 高难有难度：基础难度友好，M2 再用"市场环境"分级加难。

## 1. 一局的结构

- 主角是散户（M0 只有一个默认人设"小韭"）。开局账户 ¥100,000，持仓 4 格，没有道具，群里有 6 个群友。
- 一局 12 个月，每月 5 个交易日（10 月国庆只有 3 个），共 58 个交易日，约 15–20 分钟。
- 每月最后一个交易日收盘后还月供：账户扣掉当月账单。账户不够就爆仓，本局结束。
  还完之后三选一领奖励（第 7 节），偶尔触发一个事件（第 9 节）。
- 还清 12 个月即通关，最终账户余额记入纪录。

### 2.2 题材生命周期（隐藏状态）

题材按六个阶段循环：冷门 → 萌芽 → 发酵 → 主升 → 高潮 → 退潮 → 冷门。
另有两条"失败"的岔路：萌芽可能直接回到冷门（假启动），发酵可能直接进入退潮（题材证伪）。

| 阶段 | 持续天数（初版） | 每天热度变化 ΔH |
|---|---|---|
| cold 冷门 | 8–22（热度缓慢回落到 15） | 约 0，±2 |
| sprout 萌芽 | 2–4 | +3 ~ +8 |
| ferment 发酵 | 2–4 | +5 ~ +12 |
| rally 主升 | 2–5 | +8 ~ +18 |
| climax 高潮 | 1–3 | −5 ~ +10（剧烈震荡） |
| ebb 退潮 | 3–6 | −25 ~ −8 |

- 热度 H 的范围是 0–100，公开显示。热度触顶时强制进入高潮或退潮。
- 题材当日涨幅 = 0.45% × ΔH + 噪声（±0.5%）。各题材的性格是速度、振幅、噪声三个系数。
- 玩家看到的是热度、近 5 日热度走势，以及据此算出的"体感"标签（冷门 / 升温 / 火热 / 过热 / 降温）。
  这个标签只由公开数据算出，**不等于**真实阶段：主升和高潮看起来都是"火热"，接下来会怎样，要靠群聊和经验判断。
- **大盘**：牛 / 平 / 熊三态，持续性很强（0.9），每天给所有股票叠加 +0.5% / 0 / −0.5%，再加一点噪声。
  画面上用窗外的天气表示。

### 2.3 股票与角色

股票 = 题材 × 角色。当日涨幅 = 题材系数 × 题材涨幅 + 大盘系数 × 大盘涨幅 + 个股噪声，涨跌停 ±10%。

| 角色 | 题材系数 | 噪声 | 特点 |
|---|---|---|---|
| leader 龙头 | 1.5 | 1.0% | 题材的代表。龙头涨停时，同题材的跟风股全部 +2% |
| follower 跟风 | 0.8 | 1.5% | 跟涨龙头（见上） |
| bluechip 白马 | 0.5 | 0.6% | 稳 |
| meme 妖股 | 1.0 | 4%，另有 8% 概率跳空 ±6~10% | 大起大落 |
| st ST 股 | 0.3 | 2%，涨跌停 ±5% | 每天小概率"摘帽"（之后连续几天涨停），或收到"退市警告"（两次即退市，跌 90% 并被移出持仓） |

- **连板**：收盘涨停时，连板数 +1；没涨停就清零。
  - 连板数 c 越高，第二天越强：期望涨幅 +1.5% × c。
  - 炸板概率是 10% × c；一旦炸板，当天按 −6% 计。

## 3. 持仓

- 每格占账户的 1/格数，空格就是现金，不涨不跌。所以多开格子能分散风险，但格子空着就会拖累收益。
- **买入**：每天开盘前，最多从群友推荐的 3 只里买 1 只，放进空格，或者替换（卖出）一只已持有的。
- **卖出**：开盘前随时可以卖出已持有的股票，但当天买入的不能卖（T+1）。卖出后格子变成现金。
- 个股持有收益要显示，连板数也要显示。M0 不收手续费。
- 账户日收益 = Σ（每格权重 × 个股涨幅），再经过道具修正。

## 4. 群聊（信息系统）

- 每天开盘前，群里出现 2–4 条题材消息：某个群友对某个题材说"涨 / 跌 / 横"，并配一句有性格的台词。
  消息说的是今天该题材热度的变化方向。
- **群友爱在拐点开口**：题材将要启动、见顶、退潮的日子，被聊到的概率更高，台词也用拐点的说法
  （"要起飞了""差不多到顶了""该跑了"）。这样消息在最关键的时刻有用，"学会信谁"才成立。
- 消息说中的概率等于该群友对这个题材的可信度。说错时，改说另外两种方向之一。
- **群友推荐股票**：每天推荐 3 只，每只都附带推荐人和一句理由。推荐偏向推荐人擅长的题材，但不保证能涨。
- 每个群友的头像上显示本局战绩，比如"说中 3/5"。收盘后，群友会对结果吐槽或甩锅。

## 5. 结算表现（一天）

开盘后按下面的顺序播放，玩家不需要操作，可以跳过：

1. 题材热度变化：升温冒火，退潮结冰，大盘天气变化。
2. 持仓股票依次揭晓涨跌：小人做表情，头顶弹出百分比。
3. 连锁反应：龙头涨停时，向同题材股票画出连线，跟风股的数字再跳一下。
4. 道具触发：道具图标闪一下，并写明改动。
5. 账户数字滚动，涨停放烟花，跌停下雨云，群友吐槽。

## 6. 月供

- 账单逐月上涨，金额也要"越来越离谱"：当前为 9,200 × 1.112^(月−1)，12 月约 ¥2.96 万，是 1 月的 3.2 倍。
  （M0 第一轮实现为几乎平坦的 ¥15,600–17,800，导致 1–7 月没有压力、名目的笑点也丢了，已决定改回上涨曲线。）
- **突发账单**：一局 2–3 次，分别落在 2–4 月、5–8 月、9–12 月三个窗口，在月初和月供一起公布，金额有大有小，名目有梗。
  例如：猫进了宠物医院、手机掉进马桶、亲戚结婚随份子、被拉进"高端理财课"。
  它让压力分布到各个月，也让玩家每个月都要看一眼账单。
- 每个月的账单有一个越来越离谱的名目：房租、健身卡续费、花呗、车贷、孩子补习班、装修、按摩椅分期、
  换新手机、学区房首付、请全家旅游、给猫买别墅、还清所有梦想。
- 月底收盘后，账单滑入：够还就盖"已还清"，不够就盖"逾期"，本局结束（信用卡道具可以救一次）。
- 账单（含突发）在月初就公布，顶栏一直显示"本月月供 ¥X · 还剩 N 天"。

## 7. 月度奖励（三选一）

还清月供后，从三张奖励卡里选一张：道具、新群友，或一只稀有股票。稀有股票当月一定处于萌芽期，
可以直接替换进持仓。奖励按稀有度抽取。M0 没有商店，道具只来自这里和事件。

- `genfeng` 跟风大法：跟风股跟涨的效果 ×2。
- `baima` 白马信仰：白马股的亏损减半。
- `yaogu` 妖股猎人：妖股涨停当天按 +15% 计（打板成功）。
- `lianban` 连板梦：连板的动量 ×2，炸板率 ×1.5。
- `dixi` 低吸大师：在冷门或退潮期买入的股票，之后每逢主升日额外 +2%。
- `zhisun` 止损单：单只持仓当日跌超 4% 时，按 −4% 卖出，格子变成现金。
- `zhiying` 止盈单：单只持仓累计盈利超过 30% 时自动卖出，并额外 +2%。

**工具：**
- `extra_slot` 多开一格：持仓格 +1（每只持仓占 1/max(4, 持仓只数)，空格不拖累）。

- `margin` 两融账户：账户日收益 ×1.15，亏损也 ×1.15。
- `ipo` 打新中签：每月初账户 +1.5%。
- `credit` 信用卡：有一次还不上月供时自动代还，下月月供 +20%。

**人脉：**

- `mood_meter` 情绪指标：题材看板显示真实阶段。

- 题材流：龙头战法 + 跟风大法 + 集中一个题材
- 打板流：妖股猎人 + 连板梦
- 稳健杠杆流：白马信仰 + 两融账户 + 打新中签

## 11. 验收（模拟，每组 ≥ 2000 局）

机器人：
- random：随机买卖。
- follower：总是买推荐里的第一只，从不卖。
- chaser：追最热的题材，热度下降就卖。
- normal：普通人。参考群友战绩，在升温早期买入，过热又遇到看空消息时卖出，分散在两个题材里。
- smart：对题材阶段做贝叶斯推断，结合群友的可信度做期望值决策。
- oracle：知道真实阶段和当天的热度变化。

| # | 项目 | 标准 |
|---|---|---|
| 1 | 技能曲线 | normal 35–50%；smart ≥ normal + 15pp；chaser ≤ normal − 10pp；follower ≤ 10%；random ≤ 3%；oracle ≥ 95% |
| 2 | 择时有意义 | smart 在萌芽或发酵期买入的平均持有收益，明显高于在高潮期买入的 |
| 3 | 集中与分散都可行 | 集中（同一时间最多 1–2 个题材）的最佳策略与分散策略通关率相差 ≤ 10pp。只拿一个题材本来就是高风险打法，不要求持平 |
| 4 | 道具 | 每个道具的价值落在基线 ±10pp 内；通关局里最常见的 3 种道具组合合计 < 30%；第 8 节的五个流派都有通关局 |
| 5 | 消息有用 | 关闭群聊后，smart 通关率至少降 15pp；**只关消息、保留推荐**时 normal 至少降 8pp、smart 至少降 4pp（消息对普通玩家最有价值；smart 能从公开热度推断大部分信息）；无脑跟群主的通关率最低 |
| 6 | 月供压力分布 | normal 的出局单月 ≤ 35%；1–2 月出局 ≤ 8%。前期的紧张感靠上涨账单和突发账单营造，不靠让人出局——用连 oracle 都扛不住的大额账单制造前期出局，等于凭运气杀人，违背"高难但公平" |
| 7 | 决策密度 | smart 在 ≥ 50% 的交易日有买或卖；每天操作 ≤ 2 次 |
| 8 | 爽点频率 | 持仓有涨停的交易日占 15–30%；≥ 30% 的局出现 3 连板以上；≥ 40% 的局触发过龙头带动 |

## 12. 工程约定

## 14. 实现中的决定和细化（M0 第一轮，2026-10-10）

- 推荐质量取决于推荐人的可信度：靠谱的群友推荐的股票更可能处在好阶段；群主专挑高潮、退潮和妖股喊单；推荐偏向龙头。
- 消息话题按热度加权，并且偏向拐点（见第 4 节）。
- "关闭群聊"（只给模拟用）：没有消息，推荐来自"行情软件"，按角色权重随机。
- 情绪指标显示的是截至昨天收盘的真实阶段，显示今天的会剧透。
- 低吸大师的"冷门或退潮期买入"按公开的体感标签判断，玩家看得到。
- 稀有股票卡会让该题材当月进入萌芽，并且当月不会假启动。
- 年终奖事件在还完 1 月或 11 月月供后出现；新增"都不要"（skipReward）。
- 止损单遵守 T+1，也不覆盖退市的 −90%；ST 摘帽后退市警告清零；信用卡代还当月全部月供，下月月供 +20%。
- 事件在领完奖励后约 40% 概率出现。
- 验收命令：`node tools/sim.ts --accept --part a|b --runs 2000 --seed <种子>`（两部分可以并行），说明见 tools/sim.ts 顶部。
- 第二轮（2026-10-10）的取舍：
  - 第 1 项坚持 oracle ≥ 95%（技能决定上限）。第 6 项放宽为单月 ≤ 35%，去掉"前期必须有人出局"。
  - 第 5 项用 normal 衡量消息的价值。
  - 两融 ×1.08、打新每月 +1%；拐点消息权重和靠谱群友在拐点的可信度加成，见 balance.ts 的 chat.turn*。
- 第三轮（种子 r5）8 项全部达标：normal 40.9%、smart 80.5%、oracle 96.0%。
  待改进：多开一格（−3.7pp）和止盈单（−1.6pp）的价值为负，虽然在 ±10pp 以内，但"拿了反而更差"不合直觉，M1 时加强。

#### 内容

- 股票 40 只（+14）。推荐时**按角色分摊权重**：同一题材里同角色的股票多了，不会挤占龙头被推荐的机会（否则新增的跟风、白马把龙头的推荐占比从约 53% 压到 45%，
  normal 掉了约 6pp）。龙头的推荐权重同时从 2.5 提到 3.2。
- 道具 24 个（+8），效果：
  - `hot_money` 游资席位：当天第一只买入的股票当天涨停，额外 +3%。

数值在 `BALANCE.fx[persona]`。开局自带的道具不算"拿过道具"（成就"裸考"）；coder 的奖励里不出"手快"；youzi 的群主喊单权重 ×2。

| id | 名字 | 定稿 | 初稿 | 第 1 级通关率 normal / smart（种子 p1，各 2000 局） |
|---|---|---|---|---|
| `newbie` | 职场新人阿韭 | 10 万、4 格、没有道具 | 同 | 39.4% / 82.5% |
| `retiree` | 退休老周 | 8 万，白马信仰；金融、大消费必定登场；老王可信度 +0.05；**常规月供 ×0.78** | 8 万、月供不变 | 40.9% / 79.9% |

- 老周 8 万对 1 月 8600 的月供太紧（账户占比高了 25%），白马的稳又顶不上，几乎都死在前两个月。不加钱、改成"退休了开销小"，保留"本金少"的味道。
- 芳姐的打新 + 张姐 + 月供打折叠在一起太强；只去掉打折还是 56.7%，开局降到 9.4 万才和新人持平。这个通关率对开局账户很敏感（9 万 31%、9.4 万 42%、10 万 57%）。

- 大佬 30 万本金下 ×2 的月供完全压不住；×3.25 / ×3 时 normal 比开局三人设最低的还低 11.0pp，smart 低 5–8pp。
  "百万散户"在这个人设下 smart 有 1.0% 的局能拿到（其他人设 0）。

#### 难度

第 2 级以上的约束逐级叠加（第 1 级就是上面第 11 节验收的数值）。为了同时满足"第 8 级 smart < 15%、oracle ≥ 50%"，各级的取值和设计稿初稿不同。
调的时候发现：月供类的压力对 oracle 和 smart 几乎一样狠（oracle 也只能从每天 3 条推荐里买），只靠月供把 smart 压到 15% 以下时 oracle 也只剩 25%；
所以高难度主要考"信息与判断"——加大 smart 判断不了、而 oracle 知道的不确定性，月供只小幅上调：

| 级 | 名字 | 定稿 | 说明 |
|---|---|---|---|
| 2 | 震荡 | 常规月供 ×1.03；题材每天的热度变化多一层均匀 ±8 的来回拉扯（`MarketRules.dHNoise`） | 判断阶段更难；oracle 知道当天的变化，基本不受影响 |
| 3 | 熊出没 | 大盘每天额外 18% 概率直接转熊 | 从这一级起大盘大多时候是熊市 |
| 4 | 消息失真 | 群聊消息 80% 是瞎传的（可信度 c → 0.2c + 0.8/3），靠谱群友在拐点上不再更准；推荐不受影响 | 早期版本把推荐也变差，oracle 掉得和 smart 一样多，所以只动消息 |
| 5 | 强监管 | 全体股票炸板率 ×2，ST 退市警告 ×2 | 初稿 ×1.5 时几乎没有效果 |
| 6 | 股灾 | 随机一个月（4–9、11 月）月初公布"市场传闻"，并多一笔突发账单"表舅爆仓借钱"（常规月供的 25%）；那个月大盘更容易转熊；第 2–5 个交易日里的某一天（不公布）所有题材提前退潮、当天热度跌幅 ×2.5、大盘再跌 4 个点；被打下来的题材退潮后只冷 3–6 天（报复性反弹） | 没有反弹时股灾之后两三个月无事可做，连 oracle 都会被月供拖死；只有退潮时 normal 几乎不受影响（它的通关局本来就是运气局），所以加了那笔借钱 |
| 7 | 通胀 | 常规月供再 ×1.05 | 初稿 ×1.15 会让 oracle 也掉到 30%；×1.06 时第 8 级 oracle 只有 51.5%，余量太小 |
| 8 | 末日 | 月度奖励只给 2 张；坏事更坏：事件里的花费和损失 ×2，突发账单 ×1.2 | |

股灾那个月的突发账单 id 是 `bailout`（不参加平时的随机突发账单）。机器人知道这些公开规则（smart 会按"今天出事的概率"预估股灾），
normal 对传闻将信将疑、照常操作，真跌了就全卖、当月不再买（割在地板上）。

#### 档案与每日挑战

- 档案 `kaipan.profile`（version 1）和单局存档互不影响；坏了备份到 `kaipan.profile.corrupt` 再重建。调试开局（带 items / account 等字段）不计入。

- 每日挑战：`dailySetup(日期)` 由日期决定种子 `daily-日期`、人设（5 个都可能，包括没解锁的）和难度（2–5 级）；纪录单独记在 `daily[日期]`。
- 防绕过（发布前审查）：没解锁的人设或难度开的普通局不计入档案；日期晚于玩家本地今天的每日挑战不计入（`recordRun` 的 `today` 由画面传入，规则层不读时钟）；
  判重的 runId 带上全部操作的哈希，同种子再来不会被误判成同一局。
