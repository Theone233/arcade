# 素材说明

本模块没有外部素材、第三方图片和字体，全部由本模块的代码运行时画出来（美术样张只作参考，没有引用或复制进来）：

| 素材 | 来源 |
|---|---|
| 地形（面团、烤黄的表皮、炸焦的坑边、气孔和发面层纹、深褐墨线） | `src/view/terrainArt.ts`：按规则核心的地形网格用 marching squares 描轮廓，Canvas 2D 分块烘焙 |
| 远景（厨房墙、瓷砖缝、窗和云、挂着的汤勺平底锅、往下淡成的雾）、纸边和书桌 | `src/view/backdrop.ts`：Canvas 2D 开局烘焙一张；纸边的毛边用写死种子的随机数 |
| 角色（柴柴、橘子、团团、企企）、队标、名牌、图钉、画面外小牌、"出局"章 | `src/view/chars.ts`：Canvas 2D 程序画的简单造型（M1 占位，精修交给美术） |
| 炮弹（包子）、纸飞机、面粉团、碎屑、角度盘（三岔时两边的虚线） | `src/view/scene.ts` |
| 道具图标（连发 +1、连发 +2、三岔、加力 10% / 20% / 50%、纸飞机、锅盖，各有正常、压暗、去色三套颜色）和按钮上的勾、小锁、爪印 | 程序画的 SVG：`src/view/itemIcons.ts`，照美术 2026-10-21 定稿的源码改写，手写路径，不用滤镜、渐变和 id；按钮的边框和四种状态是 `src/view/style.css` |
| 界面图标（小房子、全图、风向袋、叶子、爪印、爬的箭头、蒸笼） | `src/view/hud.ts`、`src/view/lobby.ts` 里手写的 SVG |
| 选桌页的地图缩略图 | `src/view/lobby.ts`：地形网格一格一个像素 |
| 网页图标 | `index.html` 里手写的 SVG（一只包子） |

文字用系统字体。名字、角色、武器、地图、规则文字都是原创的。
